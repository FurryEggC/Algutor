## **项目的技术栈与学习路线**

### **一、前端技术栈学习路线**（重点：React + Monaco Editor）

#### **阶段1：基础夯实（1.5周）**

1. **HTML/CSS/JavaScript**
   
   - 用处：页面的显示，HTML与CSS已经大致了解，只需深入学习JS即可
   
   - [MDN Web文档](https://developer.mozilla.org/)：完成**表单操作（使用组件实现，优先级不高）**、**DOM操作（优先级不高）**、**ES6模块化 （重点）** 章节
   
   - 重点：`async/await`、`Promise`处理异步请求

2. **TypeScript（优先级不高）**
   
   - 介绍：TypeScript 是一种由微软开发的开源编程语言，它是 JavaScript 的超集，为 JavaScript 增加了静态类型系统
   
   - 用处：确保用户的操作台指令清晰无歧义（减少按钮按错）
   
   - [TypeScript官方教程](https://www.typescriptlang.org/docs/)：掌握类型注解、接口、泛型
   
   - 练习：用TS重构JS代码
     
     

#### **阶段2：React核心（重点理解）（2.5周）**

1. **React基础**
   
   - 介绍：React 是一个用于构建用户界面的 JavaScript 库，它允许开发者以组件化的方式创建交互式 UI。React 的核心理念在于声明式编程和组件化结构，这使得开发过程更加直观和高效。
   
   - 用处：让界面灵活组装
   
   - [React官方文档](https://react.dev/learn)：重点学Hooks（`useState`, `useEffect`, `useContext`）
   
   - 实战：搭建带状态管理的TODO List

2. **Next.js**
   
   - 介绍：Next.js 是一个基于 React 的框架，旨在帮助开发者构建高性能、SEO 友好的静态网站和 Web 应用。它扩展了 React 的功能，提供了许多开箱即用的特性，使开发者能够快速构建和部署生产级应用
   
   - 用处：让页面加载更快
   
   - [Next.js入门教程](https://nextjs.org/learn)：掌握`getServerSideProps`、API路由
   
   - 练习：实现一个SSR的博客页面
     
     

#### **阶段3：编辑器集成（2周）**

1. **Monaco Editor**
   
   - 介绍：Monaco Editor 是一个由微软开发的开源浏览器代码编辑器，广泛应用于 VS Code 中。它支持多种语言、语法高亮、代码折叠、自动补全等功能，适合在浏览器中实现强大的代码编辑体验
   
   - [Monaco Playground](https://microsoft.github.io/monaco-editor/playground.html)
   
   - 核心技能：
     
     - 配置语言高亮（Python/Java/JS）
     
     - 实现代码补全（自定义snippets）
     
     - 错误提示集成（结合后端API）
       
       

#### **阶段4：组件库（1周）**

- 作用：提供现成的漂亮按钮、表格、弹窗等组件，快速搭建出清晰、统一的操作界面，让教练（系统）和学生沟通更顺畅。

- **Ant Design**：[组件文档](https://ant.design/components/overview/)

- 重点：`Form`表单、`Table`数据展示、`Modal`弹窗

### **二、后端技术栈学习路线**（重点：Flask + AI模型集成）

#### **阶段1：Python基础（1周）**

- 作用：整个项目的基础

- [Python官方教程](https://docs.python.org/3/tutorial/)：重点学`类`、`装饰器`、`异步IO`

#### **阶段2：Flask开发（2周）**

1. **Flask核心**
- Flask是一个基于Python的轻量级Web框架，设计目标是简单易用、高效灵活。它适用于开发小型至中型的Web应用，特别是快速原型开发

- [Flask快速入门](https://flask.palletsprojects.com/quickstart/)

- 练习：构建RESTful API（用户登录/题目查询）
2. **数据库集成**
- 介绍：SQLAlchemy 是一个功能强大的 Python 库，它提供了一种与多种数据库进行交互的灵活方式。它支持多种数据库后端，包括 SQLite、MySQL、PostgreSQL 等，并且可以通过 ORM（对象关系映射）的方式操作数据库

- [SQLAlchemy教程](https://www.sqlalchemy.org/)：ORM操作MySQL

- 练习：设计知识点图谱的数据模型
  
  

#### **阶段3：AI模型集成（3周）**

AI模型集成指的是将训练好的人工智能模型（如CodeBERT、Transformer代码生成模型）嵌入到后端服务中，使其能够接收前端请求、处理数据并返回智能决策结果的过程。

> 给足够的上下文、知识库，依据现有的大模型、知识库制作结果反馈

1. **Hugging Face生态**
   
   - Hugging Face 是一个开源社区和公司，专注于提供**自然语言处理（NLP）** 的工具和资源。Hugging Face 提供了一个名为 Transformers 的 Python 库，该库包含了大量的预训练模型和工具，用于执行各种 NLP 任务，如文本分类、命名实体识别、问答等
   
   - [Transformers文档](https://huggingface.co/docs/transformers)：部署CodeBERT模型
   
   - 关键代码：
     
     ```python
     from transformers import AutoTokenizer, AutoModel
     tokenizer = AutoTokenizer.from_pretrained("microsoft/codebert-base")
     model = AutoModel.from_pretrained("microsoft/codebert-base")
     ```

2. **FAISS向量检索**
   
   - 作用：用于在大规模数据集中快速查找与查询点最接近的数据点
   
   - [官方GitHub案例](https://github.com/facebookresearch/faiss/wiki/Getting-started)
   
   - 重点：将题目向量化并建立索引
     
     

#### **阶段4：对话系统（2周）**

- 介绍：Rasa是一个开源的对话式AI框架，主要用于构建自定义的聊天机器人。它包含两个核心模块：Rasa NLU（自然语言理解）和Rasa Core（对话管理）。通过结合大语言模型（LLM），Rasa可以显著提升对话的智能性和灵活性。

- **Rasa框架**：[实战教程](https://rasa.com/docs/rasa/)

- 核心步骤：
  
  1. 定义NLU训练数据（`nlu.yml`）
  
  2. 配置对话规则（`stories.yml`）
  
  3. 集成知识图谱查询action

### **三、基础设施学习路线**（重点：Docker + 安全）

#### **阶段1：容器化（1周）**

- 作用：Docker 是一个开源的应用容器引擎，旨在简化应用程序的开发、部署和运行。它允许开发者将应用程序及其所有依赖项打包到一个轻量级、可移植的容器中，然后可以在任何环境中运行，无论是本地开发环境、测试环境还是生产环境

- **Docker**：[实战指南](https://docker-curriculum.com/)

- 掌握：
  
  - 编写Dockerfile（Python/Node环境）
  
  - 用`docker-compose`编排服务（Flask+MySQL）
    
    

#### **阶段2：代码安全（1周）**

1. **AST分析**
   
   - 工具：`LibCST`（Python）、`Babel`（JS）
   
   - 目标：解析用户代码生成AST，检测危险操作

2. **沙箱隔离**
   
   - 作用：用于限制 Python 代码的执行环境，防止其访问文件系统、导入模块、退出 Python 等危险操作。
   
   - 方案：用`seccomp`限制系统调用
   
   - 参考：[PySandbox](https://github.com/python-security/pysandbox)
